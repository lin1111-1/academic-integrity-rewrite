# Contributing

Thank you for helping improve evidence-preserving academic rewriting.

1. Open an issue for substantial behavior changes.
2. Fork the repository and create a focused branch.
3. Keep `skills/academic-integrity-rewrite/SKILL.md` concise; place detailed guidance in its `references/` directory.
4. Add or update tests for script behavior.
5. Run `python -m unittest discover -s tests -v` and `python scripts/validate_skill.py`.
6. Submit a pull request describing the academic use case, risk controls, and validation.

Do not submit copyrighted manuscripts, private similarity reports, personal data, fabricated citations, or tactics intended to deceive plagiarism detection. By contributing, you agree to the [Code of Conduct](CODE_OF_CONDUCT.md) and license your contribution under the MIT License.

## Triage targets

- Security or privacy reports: acknowledge within 7 days.
- Reproducible bugs: triage within 14 days.
- Feature proposals: review when they align with evidence-preserving academic rewriting.

These are best-effort targets, not service-level guarantees.

## Releases

Changes to output behavior require tests and a documented rationale in the pull request. Breaking changes to the skill contract should be called out in release notes. Maintainers may close requests that enable plagiarism, citation fabrication, detector evasion, or copyright abuse.
